# klinik-subekti

Sistem Akuntansi Klinik Subekti.
Aplikasi ini dikembangkan dengan React, Vite, Tailwind CSS, dan Supabase untuk mengelola akuntansi dan keuangan klinik.

## Fitur Utama

- Kelola COA (Chart of Accounts)
- Pencatatan Transaksi & Jurnal
- Buku Besar & Laporan Keuangan
- Manajemen Billing / Kasir
- Laporan Neraca & Laba Rugi
